# pele test data

The `.mmd` files are the flowchart examples from pele's test corpus
(`tests/corpus/flowchart-docs.json`, which collects the examples in Mermaid's
documentation). The `.svg` files are what pele 1.13.0 renders from them; the
Rust port must produce the same bytes.
